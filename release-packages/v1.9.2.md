## Changes

- Replaced the separate Timing and Reload buttons with one **⋯** menu at the top right of the lyrics panel. Choose **Timing…** or **Reload lyrics**. Earlier, Later, Reset and Match a line remain inside Timing.
- Removed the **LIVE LYRICS** heading and the tap-to-seek instruction. Tapping a synced lyric still seeks to that line.
- The menu supports first-touch activation, keyboard arrows/Home/End, Escape and outside-tap dismissal. It stays in view on small screens and follows the lyric opacity setting.
- Prefilled the official update-feed address for new installations and empty feed settings. Existing custom URLs and disabled update checks are preserved.

## Full installation for new users

Download **LiquidTouch-v1.9.2.zip** below and extract the entire archive. This is the complete theme, extension, installer, preview and source package; no previous LiquidTouch installation is required.

Install Spotify and a compatible Spicetify version, then follow the included README. In PowerShell, from the extracted **LiquidTouch** folder, run:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-Windows.ps1
```

Close Spotify when the installer requests it. For existing installations with the 1.9.0+ loader, use **Settings → Updates → Check now**, then approve the offered update. Versions 1.9.0–1.9.1 need this feed entered once if it is not configured:

```text
https://raw.githubusercontent.com/OrbitalShift4/Spotify-LiquidTouch/main/latest.json
```

The official address is already filled in v1.9.2 and remains the default for future releases. Preferences, lyric timing and listening history retain their existing keys.
