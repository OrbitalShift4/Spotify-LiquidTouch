## Changes

- **Cleaner lyrics:** removed internal source labels such as Musixmatch from the lyric view and timing panel. The empty status row collapses and the lyric area grows into that space. Relevant loading, failure and text-only messages remain. Synced lyric taps and timing corrections still work.
- **Settings → Animation speeds:** an overall multiplier plus **22 individual controls**, grouped under navigation/menus, player/artwork, lyrics/layout and visual feedback. 100% retains the original speed; 200% is twice as fast. Overall and individual speeds multiply. Playback, lyric timestamps, network timeouts and card double-tap timing are unchanged. Reduce Motion overrides movement.
- **Settings → Swipe thresholds:** **11 independent confirmation distances** for page Back, Settings Back/close, history/update sheets, player opening/closing, expanded/mini-player track skips, quick-search opening/closing and tab swiping. Dragging remains linked to the finger and commits only on release past the selected threshold. Inputs and native scrolling retain their behavior. Quick-search upward dismissal now keeps control instead of turning into page scrolling.
- Both new submenus save settings locally and have separate restore-default buttons. Existing preferences and the official prefilled update-feed address are preserved.

## Existing users

With the 1.9.0 or newer loader, use **Settings → Updates → Check now**, then approve **Update**. No installer or Spotify restart is needed for this compatible runtime update. The first launch shows brief notes with access to full notes.

If an older installation has no feed configured, enter:

```text
https://raw.githubusercontent.com/OrbitalShift4/Spotify-LiquidTouch/main/latest.json
```

## Full installation for new users

Download **LiquidTouch-v1.9.3.zip** below and extract the whole archive. It includes the full theme, extension, installers, interactive preview, source and documentation. Install Spotify and a compatible Spicetify version, then follow the included README. From PowerShell in the extracted **LiquidTouch** folder:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-Windows.ps1
```

Close Spotify when instructed. The official update feed is already filled in for future compatible updates.
