## LiquidTouch v1.9.1
A complete installation package for new users, with improved touchscreen navigation and an optional Home clock.

### What's new
- **Left-edge swipe Back:** swipe right from the left edge and release past the threshold. It closes the current sheet or Now Playing first, then returns through page history and restores scroll position.
- **Optional Home clock:** enable **Settings → Show Home clock** and choose **12-hour AM/PM** or **24-hour** format. Uses your device's local time, saves your choice, and wraps on smaller screens.
- **Cleaner update handoff:** prevents the update confirmation tap from accidentally opening Now Playing.
- Retains the Liquid Glass interface, artwork-adaptive backgrounds, independent text/lyrics/control sizing, live lyrics and local history.

### New users: download and install
Prerequisites: Spotify desktop and a compatible Spicetify installation.

1. Under **Assets**, download **LiquidTouch-v1.9.1.zip**.
2. Extract the entire ZIP. Keep the included files together.
3. Read the included README, close Spotify, and open PowerShell inside the extracted **LiquidTouch** folder.
4. Run:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Install-Windows.ps1
```

5. Reopen Spotify. Use the top-right Settings button to adjust text size, touch controls and the optional clock.

Choose **LiquidTouch-v1.9.1.zip** for installation. GitHub's automatic **Source code** archives contain this repository's publishing files.

### Enable future updates
In **LiquidTouch Settings → Updates**, enter:

```text
https://raw.githubusercontent.com/OrbitalShift4/Spotify-LiquidTouch/main/latest.json
```

Leave **Check for updates** enabled and select **Check now**. Compatible runtime updates offer **Update / Later** and show patch notes after installation. Older installations without the 1.9 loader need the full package first.

The prefilled-feed change is reserved for future versions. **v1.9.2 has been withdrawn.**
