## Reproduce current checks

Install Playwright and Sharp; use `LT_CHROME` for an existing Chromium binary if needed.

```bash
node tools/build-preview.cjs
node tests/track-context.cjs
node tests/queue-lyrics.cjs
node tests/revised-195.cjs
python3 tests/test_installer.py
node tools/build-preview.cjs --gallery
```

The track suite has nine current-runtime checks. To also run the old v1.9.7
regression reproduction, set `LT_PREVIOUS_PREVIEW` to that saved test preview.
To test recovery from the higher v1.9.8 cached test build, set `LT_TEST_UPDATE`
to its saved JSON. Both optional cases were run during final packaging.

The test host simulates service responses and does not play audio. User device
confirmation covers the requested behaviors, not every Spotify client version,
physical touchscreen or a measured CPU/GPU/RAM benchmark. Windows installer
source remains unchanged; its execution was not rerun here.
